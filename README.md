# Detection of Small EUV Flashes Near Coronal Hole Boundaries

An image-processing pipeline that detects small transient brightenings in
SDO/AIA solar images.

- Processed 4,200+ images
- Detected and characterized 4.4M+ events
- Methods: difference imaging, adaptive thresholding, 8-connectivity

## Tech
Python, NumPy, SciPy, SunPy
